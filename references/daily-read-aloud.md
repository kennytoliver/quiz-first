# 每日朗读与口头表达

朗读是**可选**环节：每天开场由主教练**主动询问一次**，用户选「要」才做。

它不是发音训练，也**不是必须做的事**——「问一次」是固定动作，「做不做」由用户定。之所以设成可选，是因为它有效但会占掉一整块时间，硬推只会让人第三天就放弃。

## 〇、为什么值得做

这件事一箭双雕：**既读进去一点东西，又练了一次把话讲清楚。**

读出声，是把别人的句子过一遍你自己的语言系统。一段材料能顺顺当当读下去，说明它已经变成你能用的语言；读着卡壳、绕口、要回头重读的地方——那就是缺口，当场暴露，比做十道选择题都快。

而且语言就是思维的边界：说不出来的东西，通常也是没想清楚的东西。读一遍再讲两遍，是给自己划一次边界——哪些话已经能张口讲，哪些还只是「看着眼熟」。

**所以它不能被砍成碎片。** 读三遍 + 讲两遍 + 回听一遍，是一个完整动作；只读一遍就完事，等于只做了热身。时间不够就整条跳过，不做缩水版。

## 一、读出声，三遍

**默读不算。** 默读只过眼睛，不过嘴，卡壳的地方你永远不知道。

- **第一遍求顺**：不管意思，先把嘴动起来，遇到别扭的句子就慢下来。
- **第二遍求准**：不吞字、不跳字、不回读。
- **第三遍求气**：按意思断句，把语气读出来。

**音量按场合调。** 在家可以大声；办公室、地铁、图书馆用微声——嘴唇和声带在动、自己能听见，就成立。不要求喊出来，只要求不默读。

读不顺的地方当场记一下，那是今天最值得注意的地方。

## 二、合上讲一遍

合上材料，**不看原文**，用自己的大白话把刚才读的讲出来。

这一遍允许讲漏、讲错、讲得乱。它的作用是暴露「其实没读懂」——看着原文觉得都懂，一合上就只剩几个模糊印象，这是最常见的情况。

讲的时候尽量覆盖四件事（不用逐条念，一次说完）：

1. 发生了什么 / 说了什么
2. 为什么值得关注
3. 和你的学习目标有什么关系
4. 你自己的判断、疑问，或还没弄明白的地方

## 三、留几个词，再讲一遍

随手记 **3–5 个关键词**，只当骨架，不写句子。

然后**只看这几个词**，再完整讲一次。

这一遍练的不是记忆，是组织：靠关键词把逻辑串起来，而不是背刚才说过的话。第一遍讲得散，第二遍通常会收得住——这个差别就是这次练到的东西。

## 四、录下来，回听

手机录音或录像，讲完回放一遍。

只听三件事，不要全面复盘：

- 哪里啰嗦、绕了半天没到点上
- 哪里跑题了
- 哪里卡住超过两秒

找到就记一条，下次注意。不用追求好听，也不用练播音腔。

## 五、材料怎么选

**材料不一定是新闻。** 近期动态、行业报告的一节、一篇被反复引用的文章、官方文档的更新说明、书里的一章，都行。

**但必须过四道门槛，缺一条就换：**

| 门槛 | 判据 |
|---|---|
| **真实** | 有出处：谁写的、什么时候发的、发在哪。查不到出处的一律不用 |
| **标杆** | 是这行里被反复提到的东西——官方文档、主流媒体、行业报告、被公认的作者，不是随便一个博主的碎碎念 |
| **有价值** | 读完能说出「这行在发生什么」或「这行怎么判断一件事的好坏」，不是纯情绪、纯口号、纯鸡汤 |
| **能读顺** | 句子是人话，不是术语堆。读不顺的材料，问题在材料不在你 |

**不要用这几类：** 营销软文、AI 批量生成的资讯聚合、标题党、通篇「据说」没有出处的传言、为了凑长度把三条不相干内容拼起来的合集。宁可选一篇短的、硬的，不要选一篇长的、水的。

**长度：** 读完一遍 1–2 分钟（约 300–500 字）。因为要读三遍，材料长一倍，时间就多一倍。整个环节 10–15 分钟是给四步法留的，不是给单次朗读留的。

学的是没有「行业动态」的科目（数学、语言、乐器、写作一类）时，换成一篇科普、一个应用案例、或者书里的一节，四步照走。

## 六、核实规则

- 默认优先检索近 **7 天**；不够时扩到近 **30 天**，并**明确说明时间范围**。
- 区分事件发生时间和信息发布时间。
- 优先一手来源；重要信息交叉确认。
- 区分事实、机构观点、媒体分析。
- 无法核实、或当下访问不到实时来源时，**不把旧内容称为「最新」**。
- 当天真没有合适的，不要硬凑；用近期的领域报告、官方公告或技术资料，并标注性质和日期。

## 七、反馈怎么给

反馈先看内容，不看口才：

- 事实有没有讲准
- 重点和逻辑清不清楚
- 有没有连回学习目标
- 有没有讲出自己的判断

**不要自动变成发音训练。** 只有确实收到可用音频、且用户想要这方面反馈时，才评价口头表现；只有文字时，不推断他讲得怎么样。

## 八、触发与降级

- 每天开场问一次（`SKILL.md` 第 1 步 ④）。选「要」才执行，选「不要」直接排今天的内容；已经进了轻量模式的不问。
- 材料当日检索，核实来源与日期。
- 平台支持定时任务才可自动推送；不支持时不得声称已主动推送。
- 错过一天从当前进度继续，不补做。
