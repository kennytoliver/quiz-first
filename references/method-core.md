# 方法内核

## 一、闭环的四步详解

### ① 诊断测试

- **位置：**学习任何东西之前。不是第 3 位，不是学完之后。
- **题怎么出：**一次只出一道，**接近真实任务**，用户大概率做不完。用完成度判层级，不是判对错。
- **为什么「做不完」反而对：**完成度给出的是连续的位置信息；对错只给一个比特。
- **揉进过程：**聊天、小任务、实战题。不要做成一整套考卷——人天生逃避测试，做成考卷他会跳过。
- **重新校准：**每走完一轮，重新测一次当前位置。
- **开场 recall（固定）：**每次会话在开场后、进主线之前，来一道口头 recall 题（上次学到哪、还记得什么、哪块模糊），再决定继续 / 复习 / 重测。
- **recall 答崩了怎么办：**recall 本身不判分、不进缺口。但用户完全想不起来时，把那个单元整体加进缺口清单（下次复测 = 明天），当天优先重讲该单元，不硬推新内容。
- **「不知道」是有效答案**，不扣分，且比编一个答案有用。
- **诊断只判层级，不收信心值**（诊断题本来就大概率做不完，信心值在这里没有信息量）。

### ② 定制学习路径

- 把目标拆成 **5 个等级**，每级写清：要掌握什么、常见错误是什么、达到什么标准才能进下一级。
- **跳过用户已会的级**（标灰），不从 L1 爬。
- 标出「你在这」的指针。
- 从阶梯里挑出最有杠杆的内容**前置**。
- 课表用 **10 次 × 2 小时**作初始模板，可按实际时间调整；时间不足时优先保留核心内容、练习和复盘。
- 已掌握的部分可以跳过，不要为了「完整」平铺。

### ③ 测考与练习

- **一次只问一个问题**，从易到难（**难度优先**）。
- 反馈分三类：哪里对 / 哪里错 / 哪里不完整。**只重新解释没掌握的部分。**
- 练习有**两重作用**，别只当纠错：
  1. 暴露假理解（看老师操作很畅快，自己上手就卡）。
  2. **补心力**——前期就做出一个东西，用户会想「我都投入这么多了」，这是能学下去的关键。
- **小产出尽量前置**，不要只放在课程最后。

### ④ 固化成结构

- AI 给：节点清单、哪些是上层、哪些互相冲突不能同时存在、哪些连接最重要。
- 用户自己画，拍照 / 扫描上传。
- AI 查：有没有漏、连接对不对、层级有没有错位。
- **AI 不代画。**别人生成的图不是你脑子里长出来的结构——AI 只给方法、规则和空框。
- 再把整个主题压成一页速查表。

## 二、三条铁律的依据

| 铁律 | 依据 |
|---|---|
| 先测后教 | 不看现状就开方案，等于不体检就开药——诊断必须先于教学。 |
| 高价值内容前置 | 学习劲头高度集中在开头那一小段时间。要把它花在最关键的内容上，而不是最入门的内容上（典型反例：背 abandon）。 |
| 图谱自己画 | 别人替你生成的图，不是你自己脑子里长出来的结构；AI 的作用是给方法和规则，图必须自己画。 |

**为什么前置是对的：**难度曲线和劲头曲线方向相反。教程按由易到难排，可人的冲劲在开头最高，之后单调往下走——照教材顺序学，等于把最猛的那股劲花在最不需要劲的地方（背 abandon），等真到难的地方，劲已经没了。编教材的人没法预判你什么时候放弃，所以他没有动力把难的提前；这件事只能你自己做。

**为什么必须图形化：**文字在大脑里不能直接成像，绝大多数人多少有点阅读障碍（丘吉尔需要专人念新闻）。人记不住文字，只记得住结构。知识不归档就没法下次调用。模型侧其实一样——AI 把东西变成向量，本质也是在某个空间坐标系里摆放位置。

## 三、贯穿全程的两个动作

- **资源筛选：**最多 5 个资源，每个说明适合谁 / 难度 / 怎么用 / 不用看哪里，再排 7 天路径。学习的陷阱不是资源太少而是太多——很多人不是在学习，是在收藏。
- **费曼讲回去：**AI 先用 12 岁能懂的话解释 → 用户用自己的话讲回去 → AI 指出哪里对 / 漏 / 混 / 用了自己也没真懂的高级词 → 重讲。

## 四、能力与边界：敢学 / 愿意学 / 会学

这是本 Skill 的能力边界，别越界承诺。

| | 靠什么 | 本 Skill 能做什么 |
|---|---|---|
| **敢学** | 用户天性 | 不管 |
| **会学** | 方法 —— **AI 可解** | 闭环里的一切：诊断、路径、测考、固化 |
| **愿意学** | 外部推力（有人盯、有人骂、有人一起） | **只能缓解，不能根治**：用小产出、集章、纸笔笔记的收获感哄着走，把你愿意自己走的时间拉长；发现负担过重就减量。真卡住时，找个能盯着你的人比换方法有用——这一块不在本 skill 能力范围内 |

所以：本 Skill 有一半的设计是为了「让人能学下去」，不是只为了「讲得对」。

## 五、退出 / 结业条件

满足以下三条才算这一轮学完，否则继续循环：

1. 阶梯图和缺口清单齐了（知道这个领域分几层、自己在哪层、差哪几块）。
2. 知识型要有知识图谱 + 一页速查表，且能**张口讲清楚**（不是看着念）；技能型要有动作分解 + 一段能看的录像，能自己指出哪步不稳。
3. 有一个可展示的成果。求职场景放作品集；非求职场景（学一门乐器、补一门学科）一段录音、一份手推稿、一张判定表都算，不必是项目。

## 六、常见误用

| 误用 | 后果 | 正确做法 |
|---|---|---|
| 跳过诊断直接开课 | 课程太简单或太难，两层不讨好 | 先出 1 道诊断题 |
| 从头按教材顺序铺 | 劲头峰值耗在入门内容上 | 高价值内容前置 |
| AI 直接生成知识图谱 | 图很好看，用户脑子里什么都没有 | 只给规则和空框 |
| 一次问 5 个问题 | 反馈延迟，找不到真缺口 | 一次一题 |
| 长篇讲解替代练习 | 用户「看懂了」但上手就废 | 讲完立刻给小练习 |
| 只有输入没有产出 | 学完拿不出东西，两周就断 | 每轮留一个小产出 |
| 把旧信息说成最新 | 用户拿去面试/决策会翻车 | 核实来源与日期，不能核实就说明 |
