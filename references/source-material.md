# 从源材料学习

默认模式是 AI 自己讲。但当学习有**指定材料**时（岗位教材、考试大纲、官方文档、一本书、一篇论文、一份代码库），必须切换到「从材料教」。

## 一、什么时候切换

| 场景 | 用哪种 |
|---|---|
| 随便学学、开眼界 | AI 自己讲 |
| 有指定教材 / 考纲 / 官方文档 | **从材料教** |
| 要拿去面试 / 考试 / 落地干活 | **从材料教**（口径必须和出处一致） |
| 材料只是一份参考 | 混合：以材料为主，AI 补例子 |

判断标准一句话：**会不会被人按某个口径考？会，就必须从材料教。**

## 二、流程（顺序固定：摸结构 → 诊断 → 切片）

1. **先摸结构，不急着讲。**
   扫目录 / 章节 / 标题层级，列出材料的骨架和篇幅，判断哪些是核心章、哪些是铺垫。输出一张结构图（见 `output-patterns.md` 图式库）。

2. **诊断。**
   结构摸清后、切片排课前，按闭环 Step ① 出一道诊断题定位用户位置——给了材料也**不许跳过诊断直接开讲**。

3. **切片。**
   材料长就按章节切成单元，每单元对应一条过关 rubric（模板见 `SKILL.md`「判定标准 → 过关」）。**不要让一次会话吃掉整章以上。**

4. **出题必须从材料里出，且能指回出处。**
   每道题、每条讲解后面带上出处：`第 3 章 §3.2` / `p.47` / `L120-135`。

5. **答案口径以材料为准。**
   材料说 A、AI 认为应该 B 时：**先按材料讲，再单独标注「业界通常还有另一种做法 B，差异在于……」**。不要偷偷改成 AI 的版本——用户拿去考试/面试会翻车。

6. **材料没覆盖的，明确说没覆盖。**
   用户问到材料外的内容，如实说「这份材料里没有」，再问要不要补充。不要用 AI 知识冒充材料内容。

## 三、防止幻觉的三条硬规则

| 规则 | 具体 |
|---|---|
| 不引用没读过的段落 | 引用前必须真的读过；没读过就说没读过 |
| 不确定就标注 | 出处写「`?p.47 附近`」，不装确定 |
| 材料与常识冲突时明说 | 列成两栏：材料口径 / 通行口径，让用户自己判断 |

## 四、材料质量的快速体检

拿到一份材料先花 1 分钟判三件事，写在开头告诉用户：

- **时效：**出版/更新日期是什么？这个领域过期速度多快？（技术类 2 年以上的要提醒）
- **立场：**是官方口径、厂商宣传、还是第三方分析？宣传材料里的「最佳实践」要打折。
- **深度：**入门 / 进阶 / 参考手册？和当前阶梯哪一级对得上？

对不上就直说，别硬讲。

## 五、提示词

> 我要按这份材料学【XX】：【粘贴内容 / 文件路径 / 链接】。
> 先别讲，先给我这份材料的结构图和篇幅判断，**再出一道诊断题定位我**，然后按章节切成单元，每单元给我一条过关标准。
> 讲的时候每条都带出处（章节或页码），材料没覆盖的直接说没覆盖。

> 我在准备【面试/考试】，口径要跟这份材料一致。材料里说的和通行做法不一样时，两栏都列出来告诉我。
