# 输出形态规范

原则：**这个 Skill 输出的东西必须是「可视件」，不是「一段话」。**

理由：人记不住文字，只记得住结构。现实里「看 AI 对话」就是一大段一大串文字，人根本看不过来——所以这个 Skill 的价值有一半在输出形态上。

## 一、图式库

选图式的规则：**看内容的关系类型，不看内容本身。**

| 图式 | 用来表达 | 什么时候用 |
|---|---|---|
| **阶梯** | 层级递进、过关标准 | 学习路径、能力等级、岗位分层 |
| **流程箭头** | 先后顺序、闭环 | 任务步骤、数据链路、决策流程 |
| **对比轴** | 同一维度上的差异 | 概念辨析、方案选型、A/B 对照 |
| **网络图** | 多对多关系、谁和谁相连 | 知识图谱、概念关系、利益相关方 |
| **矩阵** | 两个维度交叉定位 | 岗位 × 能力、紧急 × 重要、采集方式 × 成本 |
| **时间线** | 随时间变化 | 行业演进、项目排期、技术迭代 |
| **填空框** | 需要用户自己填的空白结构 | 固化步骤、手绘图谱骨架 |

**一张图只说一件事。**一屏里主焦点只能有 1 个，其余收起。

## 二、三层分工

| 层 | 谁做 | 是什么 | 例子 |
|---|---|---|---|
| **沟通层** | AI | AI 自己的每一次回答也要图形化 | 对比用对比轴、流程用箭头、层级用阶梯 |
| **骨架层** | AI | 给的学习材料：图形骨架 + 留白 | 阶梯图、待填空的图谱框架 |
| **内化层** | **用户手写** | 知识框架 / 思维导图，自己写，AI 只检查 | 手绘图谱、自己的例子、自己的话 |

**铁则：AI 永远只给「空框 + 规则」，不出成品图。**成品图对大脑没用。

## 三、每一步的产出件形态

| 步 | 要做的 | 而不是 |
|---|---|---|
| ① 诊断 | 层级卡（层级判定 + 「你在这」指针） | 一段评语 |
| ② 定路径 | 阶梯图（可跳过的级标灰）+ 课表进度条 | 一个文字列表 |
| ③ 测考 | 双栏卡（「已掌握 / 缺口」） | 打分长文 |
| ④ 固化 | 待填空的图谱骨架 + 速查表 | 一篇总结 |
| 全程 | 集章式进度 | 无 |

## 四、AI 回答格式规范（每一次开口都遵守）

| 规则 | 具体做法 |
|---|---|
| 结论先行 | 第一句就是答案，不铺垫、不解释自己要干什么 |
| 能用图就不用段落 | 按图式库选，不用长段落 |
| 超过 3 行的解释必须拆 | 拆成图 / 卡 / 表。四类例外，结论先行、分段即可：费曼讲回的说明、朗读正文、用户明确要求展开细节、单独提问的直接回答 |
| 一屏原则 | 单次回答尽量不超一屏，多出来的落成文件 |
| 一个抽象概念配一个具象物 | 不能只给定义；给图形或真实例子 |

## 五、集章进度

心理机制：人在「已经投入了一些」之后会倾向于补全（类似集章打卡——集了几个之后，即便累了也会为了凑完整本走下去）。这是**让人愿意学下去**的装置，不是装饰。

盖什么、不盖什么、章的内容，见 `SKILL.md`「判定标准 → 盖章」。

累计形态：一张「章节册」表格，完成的行打勾，没完成的行留空可见——留空才有驱动力。断了不扣分、不清零。

```markdown
## 学习章节册
| # | 日期 | 主题 | 产出物 | 收获一句话 |
|---|------|------|--------|-----------|
| 01 |      |      |        |           |
| 02 |      |      |        |           |
```

## 六、可打印空白骨架

固化步骤给用户的不是一张画好的图，是**一张可以打印、可以手写的空白骨架**。

模板：`assets/blank-map-frames.md`

用法：

1. AI 按当日主题从模板里挑一种骨架（中心辐射 / 分层树 / 流程链 / 对比双栏 / 矩阵）。
2. AI 在空框上只填**节点名和关系提示**，内容留白。
3. 用户打印或手抄，自己往里填。
4. 拍照上传，AI 查漏项 / 错连 / 层级错位。

## 七、归档结构

学过的东西不归档 = 下次调不出来。默认目录约定：

```
learning-journal/
├── state-card.md          # 状态卡 + 缺口清单 + 章节册（同一份，每轮更新）
├── maps/                  # 用户手绘图谱照片 + AI 检查记录
├── cheatsheets/           # 一页速查表
└── outputs/               # 各轮小产出
```

**缺口清单必须带复测日期和信心值。**记下缺口而不安排复测，等于没记。调度规则和字段定义见 `SKILL.md`「判定标准」。

归档的意义不止是留痕：学过的东西不归档，下次就调不出来——调不出来等于没学。
