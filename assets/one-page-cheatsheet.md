# 一页速查表

用途：五分钟内把脑子里的结构重新点亮。适合考试前、面试前、开会前、做项目之前看。

**规则：一页就是一页。**超了说明还没压缩够。

```markdown
# 【主题】速查表

## 一句话定义
（不超过 30 字，不许用术语解释术语）

## 最重要的概念（≤5 个）
| 概念 | 一句话 | 它解决什么问题 |
|------|--------|----------------|
|      |        |                |

## 3 个真实例子
1.
2.
3.

- ❌
- ❌
- ❌

## 使用前检查清单
- [ ]
- [ ]
- [ ]

## 5 个快速自测问题
1.
2.
3.
4.
5.
```

---

## 填写要求

| 项 | 要求 |
|---|---|
| 一句话定义 | 让外行听懂。做不到说明自己也没懂 |
| 概念表 | 「它解决什么问题」一栏必填——只记定义不记用途，等于没记 |
| 真实例子 | 必须来自真实场景，不能是「假设有一个 X」 |
| 常见错误 | 优先写自己踩过的 |
| 自测问题 | 至少 1 道是应用题，不能全是名词解释 |

## 配套动作

速查表做完 → 下一次到期复测时，先看着表把内容讲一遍（费曼）→ 讲不顺的地方记成缺口，按格式填进清单。
