# 可打印空白图谱骨架

用法：
1. AI 按当日主题挑一种骨架。
2. AI 只在框上填**节点名和关系提示**，内容留白。
3. 用户打印或手抄，自己往里填。
4. 拍照上传，AI 查漏项 / 错连 / 层级错位。

> 底层思路：把文字变成长短不一的框，只靠形状就能记住结构。**AI 绝不代填。**

---

## 骨架 A：中心辐射（一个核心概念向外展开）

```
                    ┌──────────────┐
                    │   核心概念    │
                    └──────┬───────┘
         ┌────────────┬────┴────┬────────────┐
    ┌────┴────┐  ┌────┴────┐ ┌──┴────┐  ┌───┴───┐
    │         │  │         │ │       │  │       │
    └─────────┘  └─────────┘ └───────┘  └───────┘
```

填什么：中心写概念，外圈写它的组成部分 / 影响因素 / 常见类型。

---

## 骨架 B：分层树（层级从属）

```
        ┌─────────────────────┐
        │      第 1 层（总）    │
        └──────────┬──────────┘
        ┌──────────┼──────────┐
   ┌────┴────┐ ┌───┴────┐ ┌───┴────┐
   │ 第 2 层  │ │ 第 2 层 │ │ 第 2 层 │
   └────┬────┘ └───┬────┘ └───┬────┘
      ┌─┴─┐      ┌─┴─┐      ┌─┴─┐
      │   │      │   │      │   │
```

填什么：上层是类别，下层是具体项。检查重点：**层级有没有错位**（把兄弟写成父子）。

---

## 骨架 C：流程链（先后顺序 / 闭环）

```
   ┌────┐    ┌────┐    ┌────┐    ┌────┐    ┌────┐
   │ ①  │───▶│ ②  │───▶│ ③  │───▶│ ④  │───▶│ ⑤  │
   └────┘    └────┘    └────┘    └────┘    └────┘
     ▲                                        │
     └──────────────── 反馈 ──────────────────┘
```

填什么：每一步做什么、输入什么、输出什么。检查重点：**有没有缺环节**（尤其是验证/反馈那一环）。

---

## 骨架 D：对比双栏（易混概念辨析）

```
            ┌───────────────┬───────────────┐
   定义     │               │               │
            ├───────────────┼───────────────┤
   典型场景 │               │               │
            ├───────────────┼───────────────┤
   代价/成本│               │               │
            ├───────────────┼───────────────┤
   常见误解 │               │               │
            └───────────────┴───────────────┘
```

填什么：同一维度两边对照。检查重点：**维度是否对齐**（不能一边写成本一边写场景）。

---

## 骨架 E：矩阵（两维度定位）

```
              │  维度 A 低      │  维度 A 高
   ───────────┼────────────────┼────────────────
   维度 B 低   │                │
   ───────────┼────────────────┼────────────────
   维度 B 高   │                │
```

填什么：每个格子里放一个真实例子。**每格必须有例子，不能只写定义。**

---

## 上传后的检查清单

AI 收到用户手绘图后，逐条检查并给出结论：

- [ ] 有没有漏掉关键节点
- [ ] 连接关系对不对（该连的没连 / 不该连的连了）
- [ ] 层级有没有错位（兄弟写成父子、上下颠倒）
- [ ] 有没有「互相冲突不能同时存在」的项被放在了一起
- [ ] 最重要的 3 条连接是否画出来并标出

**反馈只给这 5 条的结论和理由，不重画一张图给用户。**
