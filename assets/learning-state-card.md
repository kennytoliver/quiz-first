# 学习状态卡

**落地位置：**首次使用时把本文件整份复制到 `learning-journal/state-card.md`，之后只更新那份，本模板保持原样不动（否则下次会覆盖掉历史）。归档目录结构见 `references/output-patterns.md` §7。

每次学习结束后更新，下次开始时先读这张卡，再决定继续、复习或重新诊断。
只记录接续学习所需的信息，不复制冗长对话。

**没有内容就留空。**空着比编一条强——为了把表填满而编出来的记录，下次读卡时比空着更误导。

**这张卡记的是「账」，不是「学的东西」。**你在哪、欠什么、下次复习什么——都是记账。真正学到的东西在你手画的知识图谱里，那个才是成果。两张纸别混：卡是书签，图是内容。

**这不是给用户填的表。**它由 Agent 在每轮结束时整理，用户不需要看，也不需要维护。如果用户开始觉得在填表，说明 Agent 把活儿推错了人。

**不超过一屏。**只留接续下一轮必需的信息：当前位置、未清的缺口、下次复测日。已经固化的、被新结果覆盖的、三周没动过的，删掉。卡越长，下次读它越慢，越容易读到过时的东西。

```markdown
## 学习状态卡
- 学习目标：
- 当前阶梯 / 轮次：
- 上次学的单元：
- 今日主题：
- 已掌握：
- 当前缺口：
- 最近一次测考结果：
- 近期朗读主题与用户反馈：
- 下一步任务：
```

「上次学的单元」是开场 recall 的取题依据，每天结束时必须更新。

---

## 主题总览（同时学多个主题时用）

一张表管所有在学的主题。每次开始时先看这张表决定今天学哪个，再看下面的单主题状态卡。

```markdown
| 主题 | 当前阶梯 | 进度 | 下次复测 | 已固化 | 上次学习 |
|------|----------|------|----------|--------|----------|
|      |          |      |          |        |          |
```

「下次复测」填该主题所有缺口里**最早的那个日期**；没有缺口就留空。
选择顺序：**到期的复测 > 当前主线的下一单元 > 停滞最久的主题**（超过 7 天没碰的优先捞一下）。

---

## 缺口清单（带下次复测日期 + 信心值）

记下缺口而不安排复测，等于没记。间隔按「答对拉长、答错归零」动态调整，不写死天数。

```markdown
| 缺口 | 所属单元 | 发现日期 | 下次复测 | 上次信心 | 状态 |
|------|----------|----------|----------|----------|------|
|      |          |          |          |          |      |
```

**「上次信心」列不能省。**1–2 分（蒙对）即便答对了也留在清单里，不划掉。

「状态」填 **在队** / **2×3** / **已固化** 三者之一，含义和调度见 `SKILL.md`「判定标准 → 复测间隔」。
