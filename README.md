# 先考后学

## 别从第一章开始学。

装进 Agent 的学习 skill：先出一道真题，看你卡在哪，再只教那一段。

[它和别的有什么不一样](#它和让-ai-帮你学有什么不一样) · [看一个例子](#看它怎么对一个真实的人) · [你会拿到什么](#你会拿到什么) · [装上](#安装)

---

## 你大概经历过这个

想学 AI。

搜一圈，别人说：先读《Attention Is All You Need》。

你打开 PDF。第一页全是公式。你把每个符号都查了一遍，看完还是不知道它在解决什么问题。

第三天你放弃了，觉得自己不是这块料。

**你缺的不是智力，是起点。**

那篇论文是写给已经懂的人看的。你真正需要先搞明白的，是一句话：为什么需要 attention？

这句话没人先告诉你，因为它在一个「基础教材」里不算第一章。

---

## 所有教程都犯同一个错

它们默认你从零开始，所以都从第一页讲起。

但你不是零。你可能已经会一半，只卡在中间某个地方。

于是你把已经会的又学一遍，真正卡住你的那一块，一次都没被碰到。

更要命的是**劲头是递减的**。最想学的那几天，你被安排去读「什么是 X」，等真到难的地方，劲已经用完了。

---

## 所以它反过来：先考，后教

第一件事不是讲课，是给你一道**你现在大概率做不完的真题**。

你卡在第几步，那就是你的位置。

从哪里卡住，就从哪里开始学。不多一步，也不少一步。

---

## 它和「让 AI 帮你学」有什么不一样

| 常见做法 | 这个 skill |
|---|---|
| 你说想学什么，它给你一份学习路线 | 它先考你一道真题，按你卡住的地方排路线 |
| 路线从基础讲到进阶 | 把最扛打的提到最前面，剩下的按缺口补 |
| 你说「懂了」就算过 | 答对但自己没把握，按没掌握算，排复测 |
| 它画一张思维导图给你 | 它只给空框和规则，图你自己画 |
| 学完留下一段聊天记录 | 学完留下一个文件夹：状态卡、图谱、速查表、产出 |

## 看它怎么对一个真实的人

> **你说：** 我想转行做 AI 数据质检。
>
> **它给你：** 5 条农资电商评论，5 个实习生已经打好的标。你做质检——哪条标错了，错在哪。
>
> **它看你怎么起手：**
> 上来直接判 → 你还不知道质检第一步是先要口径，位置在 L1 起点前。
> 先问「有没有标注规范」→ L1 已经过了，直接从 L2 的边界判定开始。
>
> 一个动作，它定下了你在 5 级里的位置、今天的单元、和接下来两周的课表。
>
> 那天你带走的东西：一张层级卡、一份缺口清单（含复测日期）、一份 20 条的质检判定表——最后这个能直接放进作品集。

## 一轮走完，你手上有什么

```
① 诊断 → ② 定路径 → ③ 测考与练习 → ④ 固化成结构 → 回到 ①
```

不是聊天记录，是一个文件夹：

```
learning-journal/
├── state-card.md     # 你在哪、缺什么、什么时候复测
├── maps/             # 你手画的知识图谱
├── cheatsheets/      # 一页速查表
└── outputs/          # 每轮的小产出
```

| 产出 | 里面是什么 |
|---|---|
| **层级卡** | 5 级阶梯上你在哪一格，初步缺口 |
| **缺口清单** | 具体缺哪一块、哪天复测。不是「要多练」这种话 |
| **知识图谱** | 你自己画的，它只指出漏项、错连、层级错位 |
| **一页速查表** | 六栏压缩版，面试前五分钟能重新点亮结构 |

学动手技能（乐器、运动、操作类）时，后两件换成动作分解和一段录像。

## 安装

把目录放进你所用 Agent 的 skills 文件夹，名字用 `quiz-first`：

```bash
<你的 skills 目录>/quiz-first/
```

装完直接说想学什么。或者复制这句：

> 我想学【领域 / 技能】。**不要教我任何东西**，先出一道我现在大概率做不完的真实任务题。

---

## 你可能想先问清楚

**要钱吗？** 不要。MIT，拷进去就能用，不装依赖、不连服务、不要账号。

**会不会一直逼我打卡？** 不会。断了不扣分，累了可以切轻量模式，只做回顾不排新内容。

**只能用来学职场技能？** 不是。乐器、学科、语言都能跑，只是第 ④ 步不一样。

**它会不会替我瞎编？** 写死了：查不到来源的内容不许叫「最新」，材料里没有的就直说没有。
