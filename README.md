# 先考后学

## 答不出来，是好事。

装进 Agent 的学习 skill：第一件事不是讲课，是给你一道做不出来的题。

[它怎么运转](#它怎么运转) · [你会拿到什么](#你会拿到什么) · [装上](#安装) · [完整说明](GUIDE.md)

---

三个周末，你在学 Python。

第一个周末装环境。第二个周末看语法。第三个周末跟着教程写了个爬虫，跑通了，你还截了张图。

第四个周末，你想改一下那个爬虫。卡在第三行。

你盯着屏幕想了五分钟，发现自己说不清一句话：这个变量到底活在哪儿。

那一刻才明白过来——前三个周末你没在学 Python，你在学**怎么跟着教程走**。

---

你收藏了二十个教程、三本书、两个播客。

翻开第一章第一页，看到第三章，断了。下次回来，又从第一章第一页开始。

你不是懒。你只是从来没被谁问过一句：**你到底会不会。**

所有教程都默认你从零开始，所以它们都从零开始讲。于是你把本来就会的东西又学了一遍，真正卡住你的那一块，一次都没被碰到。

面试官问一个具体问题，你张口，脑子是空的。这不奇怪——你花了三周学的东西，本来就不是他要问的那个。

---

## 所以它先考你

第一件事不是第一章，是一道你现在大概率做不完的真题。

你卡在第几步，那就是你的位置。

从哪里卡住，就从哪里开始学。不多一步，也不少一步。

> **你说：** 我想转行做数据质检。
>
> **它给你：** 5 条评论、5 个实习生打好的标。质检一遍，哪条错了、错在哪。
>
> 你上来就判，还是先问一句「规范在哪」——这一下就把你的层级卖了。

## 它怎么运转

```
① 诊断 → ② 定路径 → ③ 测考与练习 → ④ 固化成结构 → 回到 ①
```

| 步 | 你 | 它 |
|---|---|---|
| ① 诊断 | 答一道真题，不会就写「不知道」 | 按完成度定层级，标出「你在这」 |
| ② 定路径 | 确认或修正阶梯 | 拆 5 级、跳过你会的、排课 |
| ③ 测考 | 一次答一题，答完标信心值 | 判对错、只重讲没掌握的、排复测日期 |
| ④ 固化 | 自己画图、自己复述 | 给空框和规则，只查漏、不代画 |

**三条不打折的规矩：**

- **先测后教。** 没诊断就排学习计划，等于不看病就开药。
- **高价值内容前置。** 劲头递减、难度递增，两条曲线反着走。但前置不等于跳过地基。
- **图必须你自己画。** 它画的图长不到你脑子里。

## 你会拿到什么

不是一段聊天记录，是一个文件夹：

```
learning-journal/
├── state-card.md     # 你在哪、缺什么、什么时候复测
├── maps/             # 你手画的知识图谱
├── cheatsheets/      # 一页速查表
└── outputs/          # 每轮的小产出
```

| 产出 | 里面是什么 |
|---|---|
| **层级卡** | 5 级阶梯上你在哪一格，初步缺口 |
| **缺口清单** | 具体缺哪一块、哪天复测。不是「要多练」这种话 |
| **知识图谱** | 你自己画的，它只指出漏项、错连、层级错位 |
| **一页速查表** | 六栏压缩版，面试前五分钟能重新点亮结构 |

学的是动手技能（乐器、运动、操作类）时，后两件换成动作分解和一段录像。

## 装上

把目录放进你所用 Agent 的 skills 文件夹，名字用 `quiz-first`：

```bash
<你的 skills 目录>/quiz-first/
```

装完直接说想学什么。或者复制这句：

> 我想学【领域 / 技能】。**不要教我任何东西**，先出一道我现在大概率做不完的真实任务题。

---

## 你可能想先问清楚

**要钱吗？** 不要。MIT，拷进去就能用，不装依赖、不连服务、不要账号。

**会不会一直逼我打卡？** 不会。断了不扣分，累了可以切轻量模式，只做回顾不排新内容。

**只能用来学职场技能？** 不是。乐器、学科、语言都能跑——知识型和技能型的第 ④ 步不一样，文档里分开写了。

**它会不会替我瞎编？** 文档里写死了：查不到来源的内容不许叫「最新」，材料里没有的就说没有。
