# 先考后学 · quiz-first

[English](README.en.md) | **中文**

**别再从头学了——先考你一道真题，再决定教你什么。**

---

是不是这样——

新领域，收藏了二十个教程、三本书、两个播客。
翻开第一章第一页，看到第三章，断了。
下次回来，又从第一章第一页开始。

不是你不努力。是没人告诉你：**你到底缺的是哪一块。**

---

## 它反着来：先考，后教

别的工具先讲，它先考。

你说想学什么，它不翻教材——
它出一道**你大概率做不完的真实任务题**，看你卡在哪一步。

卡住的地方，就是你该学的地方。不多一步，也不少一步。

> **你说：** 我想学数据分析。
>
> **它问：** 「手上只有一张 20 万行的订单表，老板要你明天说清『复购率为什么掉了』。你打算怎么查？」
>
> 你答到哪一步，缺哪几块就暴露了。它据此定层级、列缺口、排今天学什么——
> 而不是从教材第一页开始。

---

## 「看过」不是「学会」

| 你以为 | 其实 |
|---|---|
| 我看懂了 | 一开口就卡住 |
| 我记住了 | 三天后全忘 |
| 我学完了 | 拿不出任何东西 |

**看懂不算。讲得出、做得出、看得出错，才算。**

---

## 三条铁律

**① 先测后教。**
不体检就开药是庸医，不做诊断就排课是废课。

**② 高价值内容前置。**
劲头是递减的。别把它烧在「第一章：什么是 X」上。

**③ 图谱自己画。**
AI 画的图长不到你脑子里。它只给空框和规则——笔得你自己握。

---

## 一轮走完，你手上会有

```
① 诊断 → ② 定制路径 → ③ 测考与练习 → ④ 固化成结构 → 回到 ① 重新校准
```

- **知道自己在哪** —— 一张 5 级阶梯图，「你在这」标得清清楚楚
- **知道该学什么** —— 缺口清单 + 高价值内容优先的课表
- **学得扎实** —— 一题一测；答对却讲不出为什么，照样算没掌握
- **拿得出东西** —— 自己画的知识图谱 + 一页速查表 + 能放进作品集的小成果

---

## 它和别的学习工具不一样在哪

- 别人把导图**画给你**，它**让你自己画**——笔在自己手里才有用。
- 别人回复一大段文字，它**用图形回答**——阶梯、对比轴、可打印空白骨架。
- 别人默认你有动力，它**哄着你走**——每轮一个小产出，集章式进度。
- 别人学完你还是不懂行业，它**每天带你读行业**——读完还得讲一遍。

---

## 快速开始

把这句话发给你的 AI：

> 我想学【行业 / 技能】。**不要教我任何东西**，先出一道我现在大概率做不完的真实任务题。我答完后你判断我在哪个层级、缺什么——判得出来就停，判不出来再出下一道。

答不出就写「不知道」——这是有效答案，不扣分。

---

## 安装

把整个目录放进你所使用 Agent 的 skills 目录，**目录名用 `quiz-first`**（与 `SKILL.md` 里的 `name` 一致）：

```bash
# 常见位置
~/.claude/skills/quiz-first/
~/.codex/skills/quiz-first/
~/.workbuddy/skills/quiz-first/

# 或项目级
<项目目录>/.workbuddy/skills/quiz-first/
```

支持 `SKILL.md` + YAML frontmatter 的 Agent 都能加载。装完直接说「我想学 XX」，不用记命令。
