# 先考后学 · quiz-first

[English](README.en.md) | **中文**

一个用来自学陌生领域的 skill：从诊断开始，到能拿出成果结束。

适用于转岗、补一门学科、学一项操作技能，或任何需要连续几周推进的学习目标。

**核心做法是反过来的：先考，后教。** 没做诊断就排学习计划，等于不看病就开药。

---

## 它解决什么问题

| 卡在哪 | 具体表现 | 这套流程怎么处理 |
|---|---|---|
| **不知道缺什么** | 从第一章开始，看到第三章断了，下次又从第一章开始 | 先出一道你大概率做不完的真实任务题，按完成度定位层级，不从入门爬 |
| **顺序不对** | 最有劲的时候在背最没用的内容 | 高价值内容前置；已经会的级标灰跳过；有硬依赖的先补那一小段 |
| **看过等于学会** | 看的时候都懂，一开口就卡，一合上就忘 | 一次一题、答完收信心值、按表现排复测日期 |
| **学完拿不出东西** | 三周后只剩一个收藏夹 | 每轮留一个小产出，产出尽量前置 |

## 怎么运作

```
① 诊断 → ② 定路径 → ③ 测考与练习 → ④ 固化成结构 → 回到 ① 重新校准
```

三条不可跳过的规则：

1. **先测后教。** 诊断必须在教任何东西之前完成。
2. **高价值内容前置。** 劲头递减、难度递增，两条曲线方向相反。前置不等于跳过地基——目标内容有硬依赖时（数学记号、语言语法、代码环境），先把最小那一段补齐。
3. **图谱必须自己画。** AI 只给规则、节点清单和空框；它生成的成品图进不了你的脑子。

**目标分两类，第 ④ 步和复测节奏不同：**

| | 知识型 | 技能型 |
|---|---|---|
| 典型 | 看懂规范、摸清行业、读论文、转岗 | 弹一首歌、开车、打字、说一门外语 |
| 第 ④ 步 | 知识图谱 + 一页速查表 | 动作分解 + 录一段自评 |
| 复测 | 1 → 2 → 4 → 8 天，稳了就固化 | 间隔不超过 3 天，不设固化 |

多数目标是两者都有（学编程要懂概念，也要能写），两边都走。

## 一轮下来你会拿到什么

所有文件都落在 `learning-journal/` 目录里，不散在聊天记录中：

```
learning-journal/
├── state-card.md     # 状态卡：当前位置、缺口清单（含下次复测日）、集章记录
├── maps/             # 你手画的知识图谱照片 + AI 的检查结论
├── cheatsheets/      # 一页速查表
└── outputs/          # 每轮的小产出：判定表、推导稿、录音、bad case 分析
```

四件核心产出：

| 产出 | 内容 |
|---|---|
| **层级卡** | 你在 5 级阶梯的哪一格、初步缺口是什么 |
| **缺口清单** | 具体缺哪一块、什么时候复测。不是「要多练」这种话 |
| **知识图谱** | 自己画的，AI 只查漏项、错连、层级错位，不代画 |
| **一页速查表** | 六栏压缩版，考试、面试、开会前五分钟能重新点亮结构 |

技能型目标的产出换成：动作分解清单 + 一段能回看的录像。

## 用法

装上之后直接说想学什么，或复制这句：

> 我想学【领域 / 技能】。**不要教我任何东西**，先出一道我现在大概率做不完的真实任务题。我答完后你判断我在哪个层级、缺什么——判得出来就停，判不出来再出下一道。

答不出就写「不知道」，这是有效答案，不扣分。

`references/prompts.md` 里有 15 条现成模板，覆盖诊断、定路径、测考、复测、画图谱、速查表、资源筛选、从指定材料学等各个环节。

## 安装

把整个目录放进你所使用 Agent 的 skills 目录，**目录名用 `quiz-first`**，与 `SKILL.md` 里的 `name` 保持一致：

```bash
<你的 skills 目录>/quiz-first/
```

支持 `SKILL.md` + YAML frontmatter 的 Agent 都能加载，例如 Claude Code、Codex、WorkBuddy 及其他自建 Agent。装完直接说「我想学 XX」，不用记命令。

```
quiz-first/

├── references/
│   ├── method-core.md            # 每条规则背后的理由、能力边界、退出条件、常见误用
│   ├── output-patterns.md        # 七种图式、回答格式、可打印骨架、归档结构
│   ├── prompts.md                # 15 条提示词模板
│   ├── daily-read-aloud.md       # 每日朗读与口头表达（可选）
│   ├── dual-agent.md             # 主教练 / 答疑双角色
```

## 适用范围

**适合**：转岗准备、补一门学科、技能入门、需要连续几周推进的学习目标。

**不适合**：只问一个概念、要一条信息、让你改一段文字。这些情况直接回答就行，不需要启动这套流程——`SKILL.md` 里写明了这条边界。

**可选模块**：每日朗读。做法是每天读一段该领域的材料（300–500 字），出声读三遍、合上讲一遍、留几个关键词再讲一遍、录音回听，整个环节 10–15 分钟。它同时练阅读和口头表达，但会占掉一整块时间，所以默认可跳过，不强制。

## 来源

方法论雏形来自两个公开的中文视频（一个讲用 AI 学任何东西的六个方法，一个讲 14 年教龄老师怎么让人真的学会）。本仓库是结构化重写与扩充，不是逐句转述，也不声称核心方法由本人独创。

原视频之外，这些是本仓库补的：信心值与复测间隔调度、单元过关标准、开场回忆题、多主题调度、旧题掺入规则、从指定材料学习、轻量模式、退出条件、防幻觉条款，以及整套输出形态规范（七种图式、三层分工、可打印空白骨架、回答格式）。**每日朗读和主教练 / 答疑双角色这两块原视频完全没有**，是独立补充的设计。
