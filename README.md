# 先考后学

[English](README.en.md) | **中文**

*一个装进 Agent 的技能：先出题，再教你。*

---

你打印过一张 30 天学习计划，贴在墙上。前三天都打了勾，第四天的格子空着，到现在还在那儿。

你报过一门课，看到第五节。后来那个网页再没点开。

收藏夹里有个文件夹叫「待学」，四十几个链接，最旧的一条是三年前的。

每次都是同一个剧本：头两天很猛，做笔记、排计划、跟人说「我最近在学 X」；第四天有点卡，第五天说「明天补上」，第七天你已经不提这件事了。

到第三次，你开始怀疑一件事——是不是我这个人，就学不成东西。

---

## 不是你的问题

真正的原因通常不是懒，也不是没时间。

是你每次都在同一个地方断掉，而你**不知道那个地方在哪**。

所以每次都从最容易的地方开始：打开教程第一页，看两行，「这个我会」，心里踏实一点。一直看到第三章，撞上第一个真不懂的东西，你停下了。

下次回来，又打开第一页。因为那是唯一让你觉得「我正在学」的地方。

---

那些教程本身没错。它们只是默认你从零开始——写教程的人不知道你已经会什么，也没法知道。

于是三件事同时发生：

**你已经会的，被重新讲了一遍。** 三周过去，你复习了一堆本来就会的东西。

**真正挡住你的那块，一次都没被碰到。** 它在第 7 章，而你永远到不了第 7 章。

**劲头被花在了最不需要劲的地方。** 想学的劲头是有限的，而且在开头最足；偏偏开头安排的，都是最容易的内容。

---

## 所以它反过来做

第一件事不是讲课。

是给你一道**你现在大概率做不完的题**。

做不完是正常的——这道题本来就是用来让你做不完的。你卡在哪一处，那一处就是你真实的位置。

从哪里卡住，就从哪里开始学。不多一步，也不少一步。

整条路四步：**诊断 → 定路径 → 测考与练习 → 固化**。走完一轮，回到第一步重新校准。

最后那步「固化」，就是把学到的东西画成一张图、压成一页纸——不是复习，是把它从脑子里挪出来，摆成能看的样子。

---

## 一个具体的例子：想学 AI

你想学 AI。搜「AI 怎么入门」，得到的答案高度一致：

先学 Python，再补线性代数、概率论，然后机器学习，最后深度学习。

你从第一个开始。Python 学了两周还行，线性代数看到特征值，停下了。

三个月过去，你还在第一格门口，而且已经开始怀疑自己不是这块料。

问题不在你不努力。**「学 AI」这三个字背后，至少是三种完全不同的人：**

| 你想做的事 | 该先学的 | 完全不用碰 |
|---|---|---|
| 用 AI 做产品、调接口 | 提示词怎么写、接口怎么调、成本怎么算 | 反向传播、梯度推导 |
| 训练自己的模型 | 数据怎么清洗、损失函数是什么 | 前端、部署 |
| 进公司做数据标注 / 质检 | 标注规范、判定标准、边界 case | 一行代码都不用写 |

这三种人接下来三个月学的东西，几乎没有重叠。

而按「Python → 数学 → 机器学习」这条统一路线走，三个人都会在同一个地方停下：数学。

它不会这么开局。**它会先问你一句：你想用 AI 做什么。**

然后给你一道那个方向的真题：

- 想做数据质检 → 五条评论、五个实习生已经打好的标，让你挑出哪条标错了、错在哪
- 想调接口做产品 → 一个具体需求，让你写出能跑通的第一版提示词
- 想训练模型 → 一小批脏数据，让你说出哪几条不能进训练集

你卡在哪一步，那一步就是起点。

---

## 和直接问 AI 学，差在哪

| 常见做法 | 这个 skill |
|---|---|
| 你说想学什么，它给你一份学习路线 | 先出一道真题，按你卡住的地方排路线 |
| 路线从基础讲到进阶 | 最能带动后面的内容提到最前面，剩下的按缺口补 |
| 你说「懂了」就算过 | 答完要标信心值（4 稳 / 3 大概 / 2 猜的 / 1 纯蒙），答对但没把握按没掌握算 |
| 它画一张思维导图给你 | 它只给一副空骨架和几条规则（一张空表格，或者几个没连线的节点），结构和连接你自己摆 |
| 学完留下一段聊天记录 | 学完留下一个文件夹，里面有东西 |

---

## 一轮走完，你手上有什么

不是聊天记录，是一个文件夹：

```
learning-journal/
├── state-card.md     # 你在哪、缺什么、什么时候复测
├── maps/             # 你自己搭的知识图谱
├── cheatsheets/      # 一页速查表
└── outputs/          # 每轮的小产出
```

| 产出 | 里面是什么 |
|---|---|
| **层级卡** | 阶梯上你在哪一格，初步缺口 |
| **缺口清单** | 具体缺哪一块、哪天复测。不是「要多练」这种话 |
| **知识图谱** | 你自己搭的（纸笔或导图软件都行），它只指出漏项、错连、层级错位 |
| **一页速查表** | 六栏压缩版，面试前五分钟能重新点亮结构 |

层级卡、阶梯图、课表都不单独存文件，就写在 `state-card.md` 里——你要翻的时候只有一个地方要翻。

学动手技能（乐器、运动、操作类）时，知识图谱和一页速查表换成动作分解和一段录像。

## 安装

**需要什么**：一个支持 `SKILL.md` 的 Agent（Claude Code、Codex、WorkBuddy、Cursor 等）。不用装依赖、不用账号。核心流程不联网也能跑；只有每日朗读那个可选模块要联网检索材料。

**第一步，拿到文件。**

```bash
git clone https://github.com/kennytoliver/quiz-first.git
```

不想用 git 就点 Code → Download ZIP，解压出来的文件夹叫 `quiz-first-main`，**改名为 `quiz-first`**，否则下面的命令对不上。

**第二步，放到你 Agent 的 skills 目录。** 建议目录名用 `quiz-first`（真正决定它叫什么的是 `SKILL.md` 里的 `name` 字段，目录名不一致也能加载，只是以后不好找）：

| Agent | 默认位置 |
|---|---|
| Claude Code | `~/.claude/skills/quiz-first/` |
| Codex | `~/.codex/skills/` 或 `~/.config/codex/skills/`（看版本） |
| WorkBuddy | `~/.workbuddy/skills/quiz-first/` |
| 其他 | 通常是 `~/.<你的agent名>/skills/`，不确定就查官方文档 |

```bash
# 以 Claude Code 为例
mv quiz-first ~/.claude/skills/
```

**第三步，确认放对了。**

```bash
ls ~/.claude/skills/quiz-first/SKILL.md
```

能看到这个文件就对了。

**第四步，新开一个会话。** skill 是在会话启动时加载的，**装完必须新开一个会话**，旧会话不会自动认得它。

**验证装没装上**：新会话里直接说「我想学 XX」。它第一句应该先问你想用 AI 或这个领域做什么方向，再给你**一道题**。如果它直接开始讲概念、或者给你一份学习路线，说明没加载上——检查 `SKILL.md` 有没有放在那个目录的根上。

更细的规则见 [GUIDE.md](GUIDE.md)。
