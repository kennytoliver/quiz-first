# 先考后学

*一个装进 Agent 的技能：先出题，再教你。*

---

你打印过一张 30 天学习计划，贴在墙上。前三天都打了勾，第四天的格子空着，到现在还在那儿。

你报过一门课，看到第五节。后来那个网页再没点开。

收藏夹里有个文件夹叫「待学」，四十几个链接，最旧的一条是三年前的。

每次都是同一个剧本：头两天很猛，做笔记、排计划、跟人说「我最近在学 X」；第四天有点卡，第五天说「明天补上」，第七天你已经不提这件事了。

到第三次，你开始怀疑一件事——是不是我这个人，就学不成东西。

---

## 不是你的问题

真正的原因通常不是懒，也不是没时间。

是你每次都在同一个地方断掉，而你**不知道那个地方在哪**。

所以每次都从最容易的地方开始：打开教程第一页，看两行，「这个我会」，心里踏实一点。一直看到第三章，撞上第一个真不懂的东西，你停下了。

下次回来，又打开第一页。因为那是唯一让你觉得「我正在学」的地方。

---

那些教程本身没错。它们只是默认你从零开始——写教程的人不知道你已经会什么，也没法知道。

于是三件事同时发生：

**你已经会的，被重新讲了一遍。** 三周过去，你复习了一堆本来就会的东西。

**真正挡住你的那块，一次都没被碰到。** 它在第 7 章，而你永远到不了第 7 章。

**劲头被花在了最不需要劲的地方。** 想学的劲头是有限的，而且在开头最足；偏偏开头安排的，都是最容易的内容。

---

## 所以它反过来做

第一件事不是讲课。

是给你一道**你现在大概率做不完的题**。

做不完是正常的——这道题本来就是用来让你做不完的。你卡在第几步，第几步就是你真实的位置。

从哪里卡住，就从哪里开始学。不多一步，也不少一步。

---

## 一个具体的例子

比如你想学做汇报。

大多数人的走法是：先找模板。翻三十套模板，挑一套顺眼的，把文字填进去。做完自己看着挺完整，交上去被说「没重点」。

它不会这么开局。

它会给你五页杂乱的素材——上季度销售数据、三条客户反馈、一段会议记录——然后给一个要求：**做成三页，让老板在五分钟内决定批不批这笔预算。**

然后看你卡在哪：

- 对着素材，不知道该讲哪三页 → 问题在**结构化**，不在排版
- 知道要讲什么，排出来还是乱 → 问题在**信息层级**
- 排得清楚，但看着业余 → 问题在**审美基准**，得多拆好作品
- 做得挺好看，交上去还是被说没重点 → 问题在**受众意识**，不在技术

这四种人接下来两周练的东西完全不一样。

而如果按教材顺序，他们四个会一起从「认识界面」开始，一起在第三章放弃。

---

## 它和「让 AI 帮我学」不一样在哪

| 常见做法 | 这个 skill |
|---|---|
| 你说想学什么，它给你一份学习路线 | 先出一道真题，按你卡住的地方排路线 |
| 路线从基础讲到进阶 | 最能带动后面的内容提到最前面，剩下的按缺口补 |
| 你说「懂了」就算过 | 答对但自己没把握，按没掌握算，排复测 |
| 它画一张思维导图给你 | 它只给空框和规则，图你自己画 |
| 学完留下一段聊天记录 | 学完留下一个文件夹，里面有东西 |

---

## 一轮走完，你手上有什么

```
① 诊断 → ② 定路径 → ③ 测考与练习 → ④ 固化成结构 → 回到 ①
```

不是聊天记录，是一个文件夹：

```
learning-journal/
├── state-card.md     # 你在哪、缺什么、什么时候复测
├── maps/             # 你手画的知识图谱
├── cheatsheets/      # 一页速查表
└── outputs/          # 每轮的小产出
```

| 产出 | 里面是什么 |
|---|---|
| **层级卡** | 阶梯上你在哪一格，初步缺口 |
| **缺口清单** | 具体缺哪一块、哪天复测。不是「要多练」这种话 |
| **知识图谱** | 你自己画的，它只指出漏项、错连、层级错位 |
| **一页速查表** | 六栏压缩版，面试前五分钟能重新点亮结构 |

学动手技能（乐器、运动、操作类）时，后两件换成动作分解和一段录像。

---

## 安装

把目录放进你所用 Agent 的 skills 文件夹，名字用 `quiz-first`：

```bash
<你的 skills 目录>/quiz-first/
```

装完直接说想学什么。或者复制这句：

> 我想学【领域 / 技能】。**不要教我任何东西**，先出一道我现在大概率做不完的真实任务题。

更细的规则见 [GUIDE.md](GUIDE.md)。

---

## 几条原则

- **先测后教。** 没诊断就排课，等于不看病人就开药。
- **内容按杠杆排，不按教材排。** 但不跳过硬依赖。
- **图自己画。** 别人画好的图，进不了你的脑子。
- **答对不算会。** 讲不出来、说不出为什么，就是没掌握。
- **成果要看得见。** 聊天记录不是成果，文件才是。
